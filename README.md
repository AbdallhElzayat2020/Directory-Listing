# 📌 About

Directory Listing App is a web application that allows users to browse and manage business or service listings through a modern and responsive interface.

The project follows Laravel best practices with clean code, reusable components, validation, traits, and maintainable architecture.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/AbdallhElzayat2020/Directory-Listing.git
```

Go to project directory

```bash
cd directory-listing-app
```

Install dependencies

```bash
composer install
```

Copy environment file

```bash
cp .env.example .env
```

Generate application key

```bash
php artisan key:generate
```

Configure your database inside `.env`

Run migrations

```bash
php artisan migrate
```

Start the development server

```bash
php artisan serve
```
